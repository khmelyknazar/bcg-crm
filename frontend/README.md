# BCG CRM — frontend

Клієнтська частина CRM-системи для управління клієнтами, угодами та завданнями.
Навчальний проєкт (курсова робота), виконаний у команді: frontend — [ваше ім'я], backend — [ім'я друга].

## Технології

- React 19 + TypeScript
- Vite — збірка та dev-сервер
- Tailwind CSS 4 — стилізація
- React Router — навігація між розділами
- lucide-react — іконки

## Запуск

```bash
npm install
npm run dev
```

Інші команди:

- `npm run build` — збірка для production
- `npm run lint` — перевірка коду

## Структура

```
src/
├── components/
│   ├── clients/    # сторінка клієнтів і форма
│   ├── deals/      # дошка угод і форма
│   ├── tasks/      # список завдань і форма
│   ├── services/   # каталог послуг і форма
│   ├── ui/         # спільні елементи (Select)
│   ├── Header.tsx
│   └── Sidebar.tsx
├── config/         # список розділів навігації
├── context/        # спільні дані CRM (клієнти, угоди, завдання, послуги)
├── data/           # тестові дані (до підключення API)
├── types/          # TypeScript-типи
├── utils/          # форматування грошей і дат
├── App.tsx         # маршрути
└── main.tsx        # точка входу
```

## Функціонал

- Навігація через маршрути (`/clients`, `/deals`, `/tasks` тощо), згортання бокового меню зі збереженням стану
- Клієнти: таблиця, пошук, фільтр за статусом, додавання, редагування та видалення
- Угоди: дошка за етапами воронки з перетягуванням карток, статуси, форма угоди
- Завдання: список з відмітками виконання, строками та фільтром (у тому числі прострочені)
- Видалення клієнта прибирає і його угоди та завдання
- Послуги: каталог з назвою та ціною, пошук, додавання, редагування та видалення
- Аналітика, налаштування — у розробці

## Підключення до backend

Клієнти, угоди, завдання та етапи воронки завантажуються з API (NestJS, папка `backend/`).
Послуги поки що беруться з тестового файлу `src/data/services.ts`: на бекенді цей розділ ще не готовий.

1. Запустіть backend: за замовчуванням він працює на `http://localhost:3001`.
2. Створіть файл `frontend/.env.local` за зразком `.env.example`:

   ```
   VITE_API_URL=http://localhost:3001
   ```

3. Запустіть фронтенд командою `npm run dev`. Він працює на порту 5173: backend пропускає запити тільки з нього.
